**1. Replace openCamera() with live scanner launch:**

- Import `openLiveScanner` from `../imaging/live-scanner.js` (dynamic import is fine since it is a user-initiated action)

  - `onDone(scannedBlobs)`: Set `state.scanPages = scannedBlobs`, call `renderScanPages()`, call `updateAll()`. Do NOT call `buildPdfFromPages()` here — it will be called in `triggerExtractionFromScan`.
  - `onCancel()`: No-op (user backed out, nothing to do)
  - `onFallback()`: Fall back to the original `<input capture="environment">` flow. Create the file input element, set its `accept="image/*"` and `capture="environment"` attributes, trigger click, and wire its `change` event to the existing `handleCameraCapture` logic. **2. Fix handleCameraCapture — remove buildPdfFromPages call:**

In `handleCameraCapture(input)` (around line 407), REMOVE the `await buildPdfFromPages()` call. The function should:
- Process the captured image via `processAndRelease`
- Push `scannedBlob` to `state.scanPages`
- Call `renderScanPages()` and `updateAll()`
- Do NOT build the PDF here

**3. Fix removeScanPage — remove buildPdfFromPages call:**

In `removeScanPage` (around line 475), REPLACE the `buildPdfFromPages()` call with:
```javascript
// Clear any previously built PDF from the files array
files = files.filter(f => f.name !== 'scanned-document.pdf');
```

This removes the cached PDF so it will be rebuilt fresh on "Done - Extract".

**4. Fix triggerExtractionFromScan — add buildPdfFromPages before extraction:**

1. `await buildPdfFromPages()` — assemble all pages into PDF (single call)
2. Find the PDF file in `files[]`
3. Proceed with Claude extraction as before

**5. Update the scanZone click handler:**

The existing `container.querySelector('#scanZone').addEventListener('click', openCamera)` should still work since `openCamera` is being replaced in-place. Verify the binding is correct.

**6. Update the "add more pages" handler:**

The `addMorePages` function (around line 483-486) currently calls `openCamera()`. This should continue to work since openCamera now launches the live scanner. Verify it still works correctly — the live scanner should open again, and its `onDone` should APPEND to `state.scanPages` (not replace).

Adjust the `onDone` callback in `openCamera()` to handle the "add more pages" case: if `state.scanPages` already has items, concatenate: `state.scanPages = state.scanPages.concat(scannedBlobs)`.

**Do NOT change:** The `handleCameraCapture` still needs to exist for the fallback `<input capture>` path. The file input's change handler should still call it.
