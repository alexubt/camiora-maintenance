**Create `app/imaging/detect-worker.js`:**
```javascript
import { detectDocument } from './scanner-core.js';

self.onmessage = function({ data: { rgba, width, height } }) {
  const pixels = new Uint8ClampedArray(rgba);
  const corners = detectDocument(pixels, width, height);
  self.postMessage({ corners });
};
```
That is the complete worker. It imports detectDocument from scanner-core.js, receives a transferred ArrayBuffer, wraps it in Uint8ClampedArray, runs detection, and posts back corners (object or null). No state between messages.
