  <action>
Create `app/imaging/live-scanner.js` exporting one function:

```javascript
export function openLiveScanner(containerEl, { onDone, onCancel, onFallback })
```

**Parameters:**
- `containerEl` — DOM element to mount the scanner UI into
- `onDone(scannedBlobs)` — called when user presses "Done - Extract" with array of JPEG Blobs
- `onCancel()` — called when user presses back/close
- `onFallback()` — called if getUserMedia is unavailable (upload.js will revert to input capture)

**Module structure — internal functions:**

1. **startCamera():**
   - Check `navigator.mediaDevices?.getUserMedia` — if missing, call `onFallback()` and return
   - `getUserMedia({ video: { facingMode: { ideal: 'environment' }, width: { ideal: 1920 }, height: { ideal: 1080 } }, audio: false })`
   - On error (NotAllowedError, NotFoundError, etc.), call `onFallback()` with toast: "Camera access needed for live scanner -- using photo mode"
   - Assign stream to `videoEl.srcObject`, call `videoEl.play()`
   - Read actual resolution from `videoEl.videoWidth`, `videoEl.videoHeight` after `loadedmetadata`

2. **initWorker():**
   - `new Worker('./app/imaging/detect-worker.js', { type: 'module' })` wrapped in try/catch
   - On construction failure: set `workerSupported = false`, call `onFallback()`
   - Set `worker.onmessage` handler: update `currentCorners`, set `workerBusy = false`
   - Set `worker.onerror` handler: log warning, set `workerSupported = false`

3. **overlayLoop(timestamp):** (requestAnimationFrame loop)
   - Guard: if `!scannerActive` return (don't request next frame)
   - Throttle worker frame sending: if `!workerBusy && timestamp - lastFrameSent > 200`, call `sendFrameToWorker()`, update `lastFrameSent`
   - Lerp `displayCorners` toward `currentCorners` with factor 0.15 (smooth interpolation)
   - If `currentCorners` is null, fade out displayCorners (set to null after a short delay or immediately)
   - Call `drawOverlay(displayCorners)`
   - Request next frame

4. **sendFrameToWorker():**
   - Create temp canvas, scale video to ~360px wide (preserving aspect ratio)
   - Draw video frame onto temp canvas
   - Get ImageData, transfer the underlying ArrayBuffer to worker
   - Release temp canvas (`width = 0`)
   - Set `workerBusy = true`

5. **drawOverlay(corners):**
   - Clear overlay canvas
   - If no corners, return
   - Scale corners from video-pixel space to overlay-canvas CSS-pixel space: `x * (overlayCanvas.width / videoEl.videoWidth)`
   - Draw semi-transparent green fill: `rgba(34,197,94,0.15)`
   - Draw solid green stroke: `#22c55e`, 3px lineWidth
   - Draw corner dots: 8px radius circles, filled `#22c55e`

6. **lerpPoint(a, b, t)** and **lerpCorners(from, to, t):**
   - Simple linear interpolation helpers per RESEARCH.md

7. **syncOverlaySize():**
   - Set `overlayCanvas.width = videoEl.offsetWidth`, `overlayCanvas.height = videoEl.offsetHeight`
   - Listen on `videoEl.loadedmetadata` and `window.resize`

8. **onCapturePress():**
   - Draw current video frame to full-res capture canvas (`videoEl.videoWidth x videoEl.videoHeight`)
   - Call `flashCapture()` for visual feedback
   - Show a spinner indicator in the thumbnail area
   - Import `processImage` from `./scanner.js` — call `processImage(captureCanvas)` (HTMLCanvasElement is a valid drawable for drawImage)
   - Convert scanned canvas to JPEG blob (0.85 quality)
   - Release canvases (set width = 0)
   - Push blob to internal `scannedPages[]` array
   - Render thumbnail in the strip
   - Hide spinner, resume video feed

9. **flashCapture():**
   - Create a div with class `capture-flash`, append to scanner container
   - Remove after 300ms (CSS animation handles the fade)

10. **renderThumbnailStrip():**
    - Clear the thumbnail container
    - For each blob in scannedPages, create an `<img>` with `src = URL.createObjectURL(blob)` and a small remove button
    - On remove: `URL.revokeObjectURL`, splice from scannedPages, re-render strip

11. **onDonePress():**
    - Stop the camera stream, terminate worker, set `scannerActive = false`
    - Call `onDone(scannedPages)` with the array of JPEG Blobs

12. **exitScanner():**
    - Stop all stream tracks: `stream.getTracks().forEach(t => t.stop())`
    - Terminate worker: `worker.terminate()`
    - Set `scannerActive = false`
    - Revoke all blob URLs from thumbnails
    - Remove scanner DOM from containerEl

**DOM structure built by openLiveScanner:**
```html
<div class="live-scanner">
  <video id="liveVideo" autoplay muted playsinline></video>
  <canvas class="live-scanner__overlay"></canvas>
  <button class="live-scanner__close" aria-label="Close scanner">x</button>
  <div class="live-scanner__bottom">
    <div class="live-scanner__thumbnails"></div>
    <button class="live-scanner__capture" aria-label="Capture page"></button>
    <button class="live-scanner__done" disabled>Done - Extract</button>
  </div>
</div>
```

"Done - Extract" button is disabled until at least 1 page is captured. Enable/disable in renderThumbnailStrip.

Close button calls `exitScanner()` then `onCancel()`.

**Memory management:**
- Revoke blob URLs when thumbnails are removed or scanner exits
- Release capture canvases immediately after toBlob conversion
- Release temp canvases in sendFrameToWorker after getImageData
